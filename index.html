    Configurar

    Um por linha, na ordem do sorteio, com a quantidade antes do nome. Se preencher, o telão mostra qual prêmio está valendo. Deixe vazio para não mostrar prêmio.
    Números que concorrem
    Use quando os cadastros receberam números em sequência, por exemplo de 1 a 350.
    Pode colar direto de uma planilha. Se a linha tiver nome depois do número, ele aparece no telão. Números repetidos contam uma vez só.
    A primeira linha da planilha deve ter os títulos das colunas.
    Números que devem ficar de fora, como a equipe do stand. Separe por vírgula; use hífen para faixas.
    Histórico de sorteios
    Os números já sorteados não voltam a concorrer até você apagar o histórico.

    Os números e prêmios vieram do arquivo config.js do site. Mudanças feitas aqui valem só neste computador.

    Os números, nomes e o histórico ficam guardados só neste navegador. Nada é enviado para fora. O sorteio usa o gerador aleatório criptográfico do navegador, com a mesma chance para todos os números.
